# Handoff 2026-08-30 - Migrasi Agentic OS ke opencode

## Konteks
Claude Code OAuth expired (`Failed to authenticate: OAuth session expired and could not be refreshed`) bikin semua scheduled skills gagal (morning-briefing, status-sweep, session-journaler). User minta Agentic OS di http://localhost:4177 dimodifikasi supaya pakai opencode karena Claude tidak dapat diakses lagi.

## Yang diubah

### 1. Core agent switch (opencode sebagai default)
- `server/config.mjs:10` tambah `defaultAgent: process.env.AGENTIC_OS_AGENT || 'opencode'` dan `opencodeBin: /etc/profiles/per-user/ravi/bin/opencode`
- `server/lib/agents.mjs:6` opencode bin sekarang pakai `config.opencodeBin` + fallback `OPENCODE_BIN`, bukan hardcoded `opencode`
- `server/lib/agents.mjs:14` `getAgent()` fallback ke `AGENTIC_OS_AGENT` bukan `claude` (ponytail: default ke opencode, override via env kalau mau balik ke claude)
- `server/skills/index.mjs` 5 skills ditambah `agent: 'opencode'` + `models: {opencode: ...}`:
  - morning-briefing, status-sweep, weekly-review -> `9router/free-default` (heavy, 12-15 menit timeout)
  - session-journaler, capture -> `9router/gemini/gemini-3.5-flash-lite` (quick, 5-8 menit timeout)
- `~/.config/systemd/user/agentic-os.service.d/override.conf` baru: inject `PATH` yang include `/etc/profiles/per-user/ravi/bin` + `OPENCODE_BIN` + `AGENTIC_OS_AGENT=opencode` (fix `exited -2` karena systemd PATH tidak ada opencode, service via home-manager jadi harus pakai drop-in)

### 2. UI copy
- `src/App.jsx:131` footer `wraps claude code` -> `wraps opencode headless`
- `src/components/Header.jsx:6` subtitle `Claude Code skills` -> `opencode skills`
- `src/components/Sidebar.jsx:57` `wraps claude code headless` -> `wraps opencode headless`
- `src/components/RunConsole.jsx:66,130` spawning text + session label disesuaikan

### 3. Usage / Billing dashboard (fix list model cuma 1)
- Problem: `server/lib/usage.mjs` cuma baca `~/.claude/projects`, jadi run opencode via 9router tidak kehitung. Di Overview `BY MODEL` cuma muncul 1 model `nvidia/nemotron-3-ultra-550b-a55b`.
- Fix: `server/lib/opencode-usage.mjs` baru - baca `~/.local/share/opencode/opencode-stable.db` (dan `opencode.db` sebagai fallback) via `sqlite3 -json`, grouping per session, ambil model dari user message + tokens dari assistant message, bangun `fileAggs` format sama kayak Claude.
- `server/index.mjs:5,30,39,53` merge `scanUsage()` + `scanOpencodeUsage()` di `/api/overview`, `/api/usage`, `/api/projects`.
- Verifikasi: `curl /api/overview` today `byModel` dari 1 -> 4 (`nvidia/nemotron`, `opencode/muse-spark`, `9router/gemini/gemini-3.5-flash-lite`, `9router/free-default`), `2026-08-30` 119 msgs.
